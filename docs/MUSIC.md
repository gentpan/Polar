# 首页说说与音乐

首页 Hero 下方显示独占一行的「最新说说」，音乐胶囊固定在右下角。说说读取最近一条已发布、无密码的 feng_talk，点击进入对应说说详情。

在「外观 → Polar 主题设置 → 音乐播放器」添加歌曲：

1. 点击「添加歌曲」，在音频地址旁选择媒体，上传自己的 MP3。
2. 填写歌名、歌手，可选封面。支持粘贴 LRC 时间轴歌词，也支持普通文本歌词。
3. 上下移动调整顺序，点击页面下方「保存 Polar 设置」。最多 30 首。

播放器首次点击才加载音频，不自动播放。支持播放/暂停、上下首、进度拖动、音量、歌单选择及同步歌词。歌单顺序播放至最后一首停止；失败可重试或换歌。

音频实例保留在页面运行环境内，站内 PJAX 切换不重建音频；播放器在各页保持右下角位置。完整刷新、关闭标签页或跳到后台会停止播放。首页没有配置音乐时显示待添加状态。

音频上传沿用 WordPress 媒体库和服务器限制，设置页显示当前单文件上限。主题不会改动服务器上传限制。音频与封面地址仅接受 HTTP(S)；歌词及歌曲名称以纯文本输出，不执行 HTML。歌词同步依赖提供的时间戳，不自动转录 MP3。

已验证：空歌单、双曲目切换、90 秒临时音频播放、进度归零、时间轴歌词、跨页继续播放且无重复播放器、原生媒体选择窗口、390px 预览。临时音频和测试歌单已移除。
