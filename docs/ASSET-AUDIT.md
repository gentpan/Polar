# JS / CSS 清理记录

本轮检查覆盖主题业务源码、当前发布资源、图标模块引用图和打包顺序。未重新设计页面，也未改变数据或权限规则。

## 已处理

- 删除已停止加载的 Morphicons 源码、依赖目录及旧 bundle；删除无引用的 Lucide 组件和旧齿轮 JSON。保留仍在使用的原始 Lordicon JSON、字体与第三方许可。
- 删除 279 条已无 PHP、JS、TS 或 SVG 生产者的旧界面选择器分支，包括旧 Hero、旧控制面板布局、已移除的搜索框与周动态区域。
- 清理 50 处完全重复的 CSS 声明（42 处文件内、8 处跨文件）。不跨媒体条件重排规则；后台共用样式不依赖前台专用文件来去重。
- 删除 3 个无引用的历史动画 keyframes，以及旧 Morph/RSS 动画配套样式。
- 合并页头 Lordicon 播放器实现与正文/评论图标生命周期，移除已不可达的旧骰子和 RSS 分支。移除两个无用变量。
- 用显式 `tools/polar-assets/bundle-order.json` 替代历史 HTML 快照决定构建顺序，保留原依赖顺序。构建不再请求首页或下载字体。

- `python3 tools/polar-assets/build.py`：构建通过。

- 29 个未打包业务 JS 的无用变量、不可达代码、重复参数、重复对象键检查通过。
- 本地图标模块引用图无缺失引用或遗留孤立模块。
- 浏览器检查：首页、控制面板、说说、文章、存档、友链动态、旅行地图、后台设置；首页手机端无横向溢出。
- 交互检查：搜索展开/收起、RSS 复制反馈、评论回复/取消、推荐文章刷新和页头导航。

主 CSS 从 525,828 字节降至 499,385 字节；主 JS 从 1,044,653 字节降至 1,037,625 字节（未压缩传输大小）。
