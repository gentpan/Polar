# Polar · 极地

记录生活，自有光芒。

极地是一款个人博客主题，以留白、蓝色点缀、圆角内容卡片和深浅配色，组织文章、说说与旅行记录。

## 功能

- 分类文章切换、特色图预览与分页。
- 说说发布与管理，评论互动与等级。
- 独立足迹页、多种地图风格与平面、立体、地球视图。
- 友链动态、季节页脚、音乐和宠物陪伴。
- 可配置 AI 功能，外部地图、天气等服务按需连接。

## 技术

主体采用 WordPress 模板与 PHP、原生 JavaScript、CSS；局部交互使用 React 19、Motion、Lucide 和 Lottie，图标同时使用 Font Awesome。前端资源由 esbuild 与 Python 构建脚本整理。地图可使用 Mapbox GL JS、Google Maps 或高德。

## 品牌资源

- `assets/images/brand/polar-icon.png`：AI 生成的极地图标，后台主题设置使用。PNG 位图，不冒充 SVG 矢量文件。
- `screenshot.png`：AI 生成的主题概念预览图，供 WordPress 外观页面显示，并非运行页面的实拍截图。

主题版本与运行要求以根目录 style.css 为准。
