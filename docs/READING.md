# 阅读功能

文章页的底部阅读工具条提供：目录与实时进度、专注阅读、打印、回到正文开头。目录自动收集正文 H2/H3/H4，随滚动高亮；展开目录时，当前章节自动保持在可见区域。手机采用同一紧凑工具条，不另加宽侧栏。

章节标题旁的 `#` 可以复制段落链接。编辑器已经设置的 HTML 锚点会保留，未设置时按标题生成，重名自动编号。要让长期分享的地址不受修改标题影响，可在 WordPress 标题区块的「高级 → HTML 锚点」填写固定名称。没有 JavaScript 时正文与编辑器原有锚点继续可读，不显示增强工具条。

专注阅读暂时收起导航、Banner、评论和宠物，退出后恢复原滚动位置。打印使用浏览器原生打印功能，隐藏交互控件和背景、展开正文折叠内容；打印结束恢复折叠状态。可在打印面板保存为 PDF。

## 摘要

文章自定义摘要显示在正文开头的可折叠卡片。没有手写或生成的摘要时不自动从正文截取一段冒充摘要。

- 文章编辑页 → Polar AI 助手 → 一键生成摘要 → 预览/调整 → 应用到文章摘要 → 保存文章。
- 新生成并经作者应用的摘要标为「AI 辅助摘要」，附来源提示；纯手写摘要显示「内容提要」。
- AI 来源记录存入 `_feng_ai_summary` 元数据，与摘要文字对应。手动改写摘要后两者不再匹配，自动回到中性的「内容提要」标签。
- 之前没有来源记录的历史摘要不会被推断为 AI 内容。
- 不在访客阅读时自动调用模型。真实生成仍需后台配置自己的文字模型和密钥。
- 密码文章解锁前不输出摘要，公开 REST 不返回 AI 来源元数据。

## 正文组件

在 WordPress 区块编辑器「样板 → Polar · 阅读组件」中插入「阅读提示卡」或「折叠问答」。段落和组合区块的「样式」中可选说明、小提示、注意事项，全部使用 WordPress 原生区块，切换主题后正文不会丢失。

宽表格可横向滚动和键盘聚焦，不挤宽手机页面；代码块保留复制、等宽排版与语言标识（使用 `language-js` 等类名）。补充了行内代码、高亮、分隔线、折叠内容的样式。原有正文图片点击放大继续生效。

文末「再读一篇」显示最多三篇同分类公开文章，排除当前、私密和密码文章；没有同分类文章时不显示。

## 实现与验证

`inc/inc-reading.php`、`template-parts/reading-*.php`、`assets/js/reading.js`、`assets/css/reading.css`。沿用四个主题顶层目录，未添加额外插件或第三方脚本。资源随公共依赖加载，功能仅在可阅读的文章页挂载，切页清理事件、观察器、专注状态。

服务端验证覆盖手写/AI 来源、手改摘要、密码与公开 REST、未登录写入拒绝、作者保存、相关推荐及区块注册。浏览器验证了长文章目录、重名标题、章节跳转与高亮、百分比、专注开关、退出文章清理和 390px 布局。AI 来源测试使用临时验收文字，不代表真实模型生成；未配置供应商密钥，未发生付费请求。测试文章和临时手机预览文件完成后清理。
