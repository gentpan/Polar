# 旅行足迹地图配置

启用主题后，分类别名 `travel` 使用专属地图模板。进入 WordPress「外观 → Polar 设置 → 地图服务」选择地图服务并保存站长自己的凭据。默认 Mapbox，主题不附带共享 Key。

| 服务 | 后台需要填写 | 用途 |
| --- | --- | --- |
| Mapbox | `pk.` 开头的公开 Token | 地球地图、Geocoding v6 地点搜索 |
| Google Maps | 浏览器 Key、服务器 Key | Maps JavaScript API / 浏览器 Geocoding、服务端 Geocoding API |
| 高德地图 | Web 端 JS Key、JS 安全密钥、Web 服务 Key | 浏览器地图及服务端地址搜索 |

凭据输入框留空保留原值，勾选清除后保存才删除。切换服务保留其他服务的凭据。浏览器使用的凭据会发送到前端，按服务商要求设置域名限制；Google 和高德的服务器 Key 不输出到前端。高德可配置站长自行部署的 HTTPS 安全代理地址。

Mapbox 搜索使用 Permanent Geocoding，账户需具备对应权限及计费资格。Google 搜索保存 Place ID，展示时在 Google 地图解析坐标，不长期保存其返回的经纬度。高德搜索标记为 GCJ-02，手动 WGS84 点在高德地图展示前转换。服务商搜索结果绑定来源；更换地图服务后需要重新搜索选点，手动坐标按坐标系处理。

在文章编辑页「旅行足迹」搜索城市或地址，点击候选结果，再保存文章。也可手填城市、国家、两位国家代码、经纬度、坐标系和备注。文章加入 travel 分类后显示在旅行页。国旗地址为 `https://flagcdn.io/flags/4x3/{小写国家代码}.svg`。

前台只输出已发布、无密码保护的旅行文章点位。未填 Key 或地图加载失败时，文章列表和站内地点筛选仍可使用。地图按需加载，PJAX 离开时销毁实例。外部地点搜索仅允许有文章编辑权限的登录用户，检查 nonce 并限频。
