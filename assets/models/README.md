# Animated animal assets

fox.glb, shiba.glb, husky.glb and deer.glb are converted without geometry or animation changes from Quaternius **Ultimate Animated Animal Pack** (July 2021).
Source: https://quaternius.com/packs/ultimateanimatedanimals.html
License: CC0 1.0 https://creativecommons.org/publicdomain/zero/1.0/
Download: https://drive.google.com/drive/folders/1uJ3N5HfB7jKTseJUNQr3N4YaN0UuEtHk

Original embedded glTF JSON was packed into GLB, preserving buffers, skins and all authored clips. Only the selected animal is loaded. Author credit is retained voluntarily.

Three.js runtime is MIT licensed; see THREE-LICENSE.txt. Source code is ../js/src/pet-3d.js. Bundle with esbuild (`--bundle --minify --format=esm`) and installed `three` to ../js/pet-3d-runtime.js.
