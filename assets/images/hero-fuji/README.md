# 富士山智能 Hero

七张同构图背景：dawn / day / sunset / night / cloud / rain / snow。
使用内置 image_gen 生成，原图保留在生成目录；本目录为 cwebp quality 84 的 WebP 成品。提示词见 prompts.json。

主题设置 → 首页与内容：
- Hero 智能山水背景：关闭后恢复原四季图设置。
- Hero 云层与雨雪动画：开关独立于天气图标动画。
- Hero 场景预览：自动或七种固定场景，测试完成后选自动。

自动模式只影响 Hero，不更改整站主题。天气来自访客 IP 估算地点；本地环境使用公网出口地点。没有访客天气时按浏览器本地时间判断晨昼暮夜，不采用博主城市作为访客位置。天气每 20 分钟刷新，场景时钟每分钟更新。只在图片解码成功后淡入，不预加载全部七张。

日出日落取 Open-Meteo daily sunrise/sunset，UTC epoch 格式；时区偏移由接口提供。太阳位置是跟随白昼进度的示意弧线；月亮是夜间装饰，不模拟真实月相或天文位置。极昼极夜以接口 is_day 兜底。阴雨雪的夜间版本使用对应天气图降低亮度。

API 文档：https://open-meteo.com/en/docs
页面不可见、Hero 离开视口时暂停动画；减少动态效果偏好会停用动画与过渡。管理员预览只改变背景，不伪造真实天气文字。
